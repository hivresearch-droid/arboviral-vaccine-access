# Licensing and reuse

No open-data licence has been assigned in this package.

Uploading the files to GitHub does not by itself grant unrestricted reuse rights. Before making the repository public, the authors should select an appropriate licence consistent with the journal's requirements and the terms of the underlying sources.

Common options for an original research dataset include Creative Commons Attribution 4.0 International (CC BY 4.0) or Creative Commons Zero (CC0 1.0), but the appropriate choice remains the authors' decision.
