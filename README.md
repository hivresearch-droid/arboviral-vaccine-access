# Arboviral vaccine access map — Supplementary Dataset S1

This repository contains the country-level dataset supporting the manuscript:

**From vaccine availability to effective deployment: closing the arboviral vaccine access gap**

**Authors:** Kok Keng Tee, Dongkui Mu, Binghui Wang, and Xueshan Xia

## Dataset overview

- **Assessment cutoff:** 6 May 2026
- **Primary analytical scope:** 195 sovereign states
- **Viruses assessed:** dengue virus (DENV), chikungunya virus (CHIKV), Japanese encephalitis virus (JEV), and yellow fever virus (YFV)
- **Primary dataset:** 780 country–virus records
- **Secondary dataset:** preserved 249-country/territory tables for sensitivity analyses
- **Unit of analysis:** jurisdiction

The dataset describes jurisdiction-level transmission, vector occurrence, regulatory approval, market availability, public-programme status, programme scope, eligibility restrictions, and evidence linkage. It does **not** estimate individual-level vaccine uptake, coverage, effectiveness, or population protection.

## Repository contents

- `Supplementary_Dataset_S1.xlsx` — authoritative analytical workbook
- `data/` — CSV exports of each worksheet for convenient browsing and reuse
- `CITATION.cff` — citation metadata
- `DATA_DICTIONARY.md` — brief description of the workbook sheets and key interpretation notes
- `LICENSE_NOTE.md` — licensing and reuse note
- `CHECKSUMS.sha256` — SHA-256 checksums for file-integrity verification

The Excel workbook is the authoritative version. CSV files are convenience exports and contain displayed cell values rather than workbook formatting or formulas.

## Reproducibility

No separate analytical code was used. All analyses were descriptive and consisted of deterministic tabulations and percentage calculations performed directly from the country-level dataset. The workbook contains the classifications, operational definitions, analytical decisions, source identifiers, and summary calculations required to reproduce the reported results.
