# Arboviral vaccine access

This repository contains **Supplementary Dataset S1** accompanying the manuscript:

**From vaccine availability to effective deployment: closing the arboviral vaccine access gap**

The dataset provides jurisdiction-level classifications of transmission status, vector occurrence, regulatory approval, market availability, public programme implementation, programme scope, eligibility restrictions, and evidence linkage for dengue virus (DENV), chikungunya virus (CHIKV), Japanese encephalitis virus (JEV), and yellow fever virus (YFV).

The Excel workbook is the authoritative version of the dataset used in the manuscript. It includes the complete country-level dataset, operational definitions, analytical decisions, source inventory, and summary tables required to reproduce the descriptive analyses reported in the manuscript.
